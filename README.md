# Tcl Scripting Journey

A hands-on collection of Tcl scripting exercises focused on programming fundamentals, automation, file processing, and EDA-oriented workflows.

## Goals

- Learn Tcl syntax and programming fundamentals
- Practice data handling and control flow
- Automate file and text-processing tasks
- Work with regular expressions and error handling
- Explore Tcl-based EDA automation

## Environment

- Tcl 9.0.4
- Visual Studio Code
- Git

## Structure

The repository is organized by concepts and automation skills rather than by a day-by-day sequence.
